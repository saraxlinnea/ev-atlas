# EV Atlas

A comparison of 20 EVs where every spec is individually sourced. I built it
to learn automotive engineering by tracking down each number myself instead
of reading someone else's summary.

Each value carries a source tier (primary / secondary / derived /
unverified), a URL, and an access date. `docs/METHODOLOGY.md` covers the
sourcing rules; its [Known limitations](docs/METHODOLOGY.md#known-limitations)
section lists what isn't trustworthy yet.

## Layout

```
schema/            JSON Schemas for a claim and a vehicle, plus the field
                   dictionary (units, typical source tier per field)
data/
  vehicles.json            vehicle registry (identity only, no specs)
  flattened.csv            generated: one row per vehicle, for charts
  disclosure_heatmap.csv   generated: vehicle x field -> tier
claims/            one JSON file per vehicle; the source of truth for every number
scripts/
  validate.py      schema and sourcing-rule checks; run before every commit
  flatten.py       claims/*.json -> data/*.csv
  build_site.py    copies chart CSVs/specs into site/ for preview and Pages
charts/            Vega-Lite specs; read only from data/*.csv
site/              static pages (index, compare, charts, methodology + CSS);
                   site/data/compare.json and site/data/*.csv plus site/charts/
                   are generated by build_site.py (site/data and site/charts gitignored)
docs/
  METHODOLOGY.md   sourcing rules and known gaps
AGENTS.md          instructions for AI coding agents (Cursor, Claude Code)
```

## Status (2026-10-02)

- Schema, validator, and flattener work.
- Vehicles are MY2026 except Rivian R2 and Chevrolet Bolt (MY2027) and
  Hyundai Ioniq 6 (MY2025), which weren't sold as 2026 models.
- All 20 vehicles have NHTSA recall claims for their model year
  (recallsByVehicle API, cross-checked against NHTSA's recall flat file).
- All 20 vehicles have EPA range, efficiency, MPGe, and drive layout from
  fueleconomy.gov (Bolt EPA id 50372; trim recorded as LT).
- Lucid Air Pure, Tesla Model Y/3/S, plus Phase C OEM core for Ioniq 5/6,
  EV6, Equinox EV, Lyriq, Mach-E, ID.4, EX30, R1T, R2, and Gravity Touring.
  Follow-up OEM core: Porsche Taycan, Mercedes CLA 250+, Nissan Leaf S+,
  and Chevrolet Bolt LT. BMW i4 eDrive35 still has no 2026 US OEM page
  (lineup is eDrive40+); no eDrive40 mapping invented.
- Sale status: only the 2027 Chevrolet Bolt LT is marked `current`
  (Chevrolet OEM/newsroom). The other 19 remain `unverified_availability`.
- Charts page has EPA efficiency, battery-side vs wall-side, and the
  disclosure heatmap. Evolution-over-time and architecture scatter views
  aren't built.
- Static site preview is available (Home intro, Compare table, Charts,
  Methods); GitHub Pages deploys from `site/` after validate + flatten + build.

## Running it

```
pip install -r requirements.txt
python scripts/validate.py
python scripts/flatten.py
```

## Preview the page

```
npm run build:site
npm run preview
```

That regenerates the CSVs, copies them into `site/`, and serves
`http://localhost:4173`. Or without npm:

```
python scripts/flatten.py
python scripts/build_site.py
python3 -m http.server 4173 --directory site
```

Vega-Lite specs live in `charts/` (including the disclosure heatmap) for
any Vega-Lite viewer.
